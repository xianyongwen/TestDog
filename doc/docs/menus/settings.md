## 语言

界面显示语言（简体中文 / English），切换后立即生效。

## 外观

主题模式：**浅色 / 深色 / 跟随系统**。跟随系统时自动适配 macOS 明暗外观。

## AI 网关配置

AI 生成与自愈需要 LLM，通过 **OpenAI 兼容协议**调用自定义网关/代理：

| 配置项 | 说明 |
| --- | --- |
| 网关地址 | OpenAI 兼容协议 baseURL |
| 密钥 | 已设置时脱敏显示，留空表示不修改 |
| 模型名 | 默认模型；AI 生成、自愈定位、AI 修复共用 |
| 模型具备视觉能力 | 开启后图片附件与页面截图以多模态直发主模型，生成循环提供 `see` 视觉观察工具；关闭则不发送图片 |
| 思考深度 | 控制模型的推理强度；非推理模型保持关闭 |
| 智能体最大步数 | 生成循环的最大步数上限 |

::: tip 模型选择建议
优先使用**具备视觉能力的模型**，效果更好：开启后 AI 能直接「看」页面截图理解界面布局，对复杂页面和自研组件的定位、操作成功率显著更高；同时图片附件也能被模型直接理解。
:::

## 浏览器配置

| 配置项 | 说明 |
| --- | --- |
| 浏览器路径 | 留空自动探测系统 Chrome；也可指定浏览器可执行文件路径 |

浏览器视口统一为 1920×1080；生产环境使用系统 Chrome。

## 提示词配置

| 配置项 | 说明 |
| --- | --- |
| 拆步提示词 | 预拆分步骤计划使用的提示词，可恢复默认 |

## 数据保留

| 配置项 | 说明 |
| --- | --- |
| 生成记录保留天数 | 过期生成记录在启动时自动清理 |

::: tip 提示
修改网关配置后，建议先用一条简单用例试跑一次生成，确认连通与模型可用。
:::
