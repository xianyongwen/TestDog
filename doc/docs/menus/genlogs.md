# 生成记录

每次 AI 生成留档：步骤级日志全程可回溯，token 消耗按差分口径记账。

## 记录列表

![生成记录列表](/images/genlogs-list.png)
<p class="doc-img-caption">生成记录：状态、用例、自然语言、步骤数、Token 消耗（含缓存命中）</p>

| 列 | 说明 |
| --- | --- |
| **状态** | 已完成 / 出错 / 已取消 |
| **用例** | 本次生成所属的用例 |
| **自然语言** | 发起生成时的描述文本 |
| **步骤数** | 本次生成执行的步数 |
| **Token 消耗** | 该次生成实际消耗的模型用量（含缓存命中标注，缓存部分成本远低于正常调用） |
| **开始 / 结束时间** | 本次生成的时间区间 |

**行操作**：

| 按钮 | 作用 |
| --- | --- |
| 👁 **查看** | 就地打开**生成记录详情**抽屉：完整的工具调用轨迹、视觉观察、求助决策与每步 token 明细 |
| 🗑 **删除** | 删除该条生成记录（确认弹窗） |

另外**点击行任意处**会跳转到**所属用例详情**，定位到该次生成产出的脚本版本，便于直接续跑或回放。

顶部工具栏：**搜索**（用例/描述关键词）、**状态筛选**、批量勾选后**清除选中** / **清除全部**。

## 记录详情里能看到什么

![生成记录详情抽屉](/images/genlog-detail.png)
<p class="doc-img-caption">生成记录详情抽屉：概要信息（状态、Token 消耗与缓存命中）+ 执行步骤明细（每步工具、参数与 token）</p>

- **概要信息**：状态、自然语言、起始地址、Token 消耗（缓存命中单列）、起止时间。
- **执行步骤**：用户输入、LLM 预拆分、导航/快照/填写/按键等每步工具调用，含参数与逐步 token 记账。
- **视觉观察**：开启视觉能力后的页面截图观察记录。
- **求助决策**：定位卡住时选择了 AI 修复 / 改述 / 手动接管 / 跳过的完整决策过程。

## 自动清理

按[设置](/menus/settings)中的「**生成记录保留天数**」，应用启动时自动清理过期记录。
