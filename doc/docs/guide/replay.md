# 回放运行

脚本写好后一键回放：Playwright 确定性执行，**回放零 LLM 成本**（仅自愈定位消耗少量 token），适合作为日常回归。

<p class="doc-video-caption">真实回放全程：运行当前版本 → 运行进度 → 完成后在运行记录中查看逐步明细</p>

## 运行入口

- **用例详情** →「**运行当前版本**」或脚本版本行的「**运行**」按钮（可先切无头模式开关、选择登录配置）。
- **用例列表** → 行操作「运行」，直接跑默认脚本版本。
- 运行过程中可**停止**；用例可**批量设置默认脚本版本**（用例列表「版本」列下拉），回归时直接跑默认版本。

## 运行过程

点击运行后，用例详情页出现「**运行进度**」卡片（附「停止运行」按钮），实时输出每步执行日志：

![运行明细](/images/replay-run-detail.png)
<p class="doc-img-caption">运行明细：逐步状态（通过/失败）、自愈标记、耗时、Token 消耗与运行日志</p>

运行完成后，切到「**运行记录**」Tab（或从全局「运行记录」菜单点「查看明细」），即可查看该次运行的完整明细：

- **逐步结果表**：每步的动作、状态（通过/失败）、**自愈**标记、耗时、Token 消耗、信息。
- **运行日志**：浏览器窗口尺寸、登录配置状态、每步 `goto / fill / press / assert → PASSED/FAILED`。
- **失败诊断**：失败步骤自动保存页面**截图**，并采集浏览器 **console 与 network** 记录。
- 右上「**导出**」：结果导出 JSON / Excel（测试报告）。

## 断言类型

| 类别 | 断言 | 说明 |
| --- | --- | --- |
| **UI 断言** | 元素可见 | 等待元素出现（自动等待，最多 10s） |
| | 元素隐藏 | 等待元素不可见/移除，适合断言 toast、loading 消失 |
| | 文本内容 | 校验元素文本 |
| | 页面 URL | 当前 URL 包含期望子串 |
| **接口断言** | 状态码 | 匹配 URL 关键词的最近响应的状态码 |
| | 响应体 | 响应体包含期望子串 |
| | JSON 字段 | 按 JSON 路径（如 `data.items.0.id`）取字段值比较 |
| **WebSocket 断言** | 发送消息 | 客户端发出的 WS 消息匹配 |
| | 接收消息 | 服务端推送的 WS 消息匹配 |

::: tip 接口/WS 断言的定位方式
`locator.value` 填 **URL 关键词子串**（如 `/api/login`），引擎命中运行期间最近一次匹配的响应/消息帧。
:::

## 唯一测试数据

步骤中的 <code v-pre>{{var}}</code> 占位符支持**系统变量**（随机手机号/邮箱/身份证等）与**项目环境变量**注入唯一测试数据，避免「手机号已注册」类的脏数据问题。变量清单与规则见[测试数据与登录态](/guide/test-data)。

## 失败自愈

- 选择器失效（前端改版导致定位不到）时，回放自动转入 **AI 自愈**：结合步骤的自然语言指令（`instruction`）重新定位元素并继续执行。
- 自愈结果可**一键采纳回写**原脚本，下次回放直接生效。

## 复盘与导出

- 全部历史运行在「**运行记录**」菜单汇总（见[运行记录](/menus/runs)），点「查看明细」回到用例详情的运行记录 Tab。
- 结果可导出 **JSON / Excel**（测试报告）。
