# 常见问题

## AI 生成会真的操作我的系统吗？

会。AI 生成不是「纸上谈兵」—— 它在**真实浏览器里真实执行**每一步（点击、输入、提交），成功后才落为脚本。因此：

- 被测系统请务必指向**测试环境**，不要指向生产环境（生成过程可能产生真实业务数据，如真实下单、真实提交）；
- 回放同样会真实执行 —— 回归回放同样请指向测试环境。

## AI 生成一直「求助」怎么办？

- 检查网关配置是否正确（[设置](/menus/settings)），先用简单用例验证连通。
- 求助时可选择**改述**：换一种说法描述操作意图，往往比原描述更容易定位。
- 复杂交互（下拉、日期等）确认插件预设已关联到项目（[插件管理](/menus/plugins)）。
- 个别页面实在定位不了，选**手动接管**直接完成该步。

## 网关连接失败？

- 确认网关地址、密钥、模型名三项都有效（在设置页检查）。
- 网关需兼容 **OpenAI 协议**（`/v1` 风格）。
- 内网网关需保证运行 TestDog 的机器能访问到。

## 找不到浏览器？

- 设置中「浏览器路径」**留空会自动探测系统 Chrome**；装了非标准位置的浏览器请手动指定路径。

## 回放报「元素定位不到」？

- 若前端近期改版，回放会自动进入 **AI 自愈**重新定位；自愈成功后记得**一键采纳回写**原脚本。
- 反复失败时，查看运行记录中失败步骤的**截图与 console/network 采集**，确认页面实际状态。
- 断言 `url` 是瞬时取值，跳转场景建议在前面加一个 `visible` 断言或短暂 `wait`。

## 插件上传后没生效？

上传 ≠ 生效。需要两步：

1. 在插件管理「**预设**」Tab 把插件加入某个预设；
2. 让测试项目**关联该预设**。

另外插件的动作清单要点一次「**试运行**」后才会回写。

## 升级安装后数据还在吗？

在。升级安装不覆盖旧数据库，启动时自动幂等迁移补齐新字段。

## 回放消耗模型 token 吗？

不消耗。回放是 Playwright 确定性执行，零 LLM 成本；只有**生成脚本**与**自愈定位**才会调用模型。

## 支持哪些组件库的复杂组件？

内置插件覆盖 **Ant Design / Element / Vant / MUI** 的下拉、树选、日期、时间、滑块、级联等组件（完整清单见[插件管理](/menus/plugins)）；其他组件库变体可上传自定义插件。

## 忘了某步为什么这么写？

- 脚本步骤有「说明」列，建议生成/编辑时每步都填。
- AI 生成的完整决策过程可在「**生成记录**」中回溯（工具调用、视觉观察、求助决策）。
