# 更新日志

记录 TestDog 各版本的功能更新与问题修复。安装包前往[下载页](/download)获取，最新版本发布说明同步发布在 [GitHub Releases](https://github.com/xianyongwen/TestDog/releases)。

## v0.1.5（2026-09-16）：项目测试文件、定位作用域与滚动动作

本次更新把 AI 生成与回放延伸到更真实的业务场景：测试文件可在项目中统一管理并随生成/回放上传，定位器支持配置作用域容器以应对弹窗与重复控件，新增滚动动作并让快照感知滚动状态。同时支持生成执行中直接发送用户纠正、增强空转防护，登录状态在浏览器关闭后也能自动保留，桌面端切换主题会同步原生窗口。

### 项目测试文件与上传

- 新增项目测试文件管理：生成时可上传项目测试文件，统一存储并按引用自动清理（24 小时宽限期 + 引用检测），不再要求文件只存在于本地。
- 新增 upload 动作：生成与回放以一致的语义执行上传，支持 `input[type=file]` 直接注入与文件选择器两种模式；禁用控件、多文件上限、等待文件选择器超时等均有明确报错。
- 生成工具新增 list_files：模型先分页查询项目测试文件再按需选用，upload 的 fileIds 必须来自该列表；文件解析统一在执行动作前完成，避免中途失败。

### 滚动动作与快照感知

- 新增 scroll 动作：支持页面滚动、滚动容器、滚动到可视区三种目标，可按 x/y 轴、按距离滚动、滚动到顶部或底部；生成与回放使用一致的 DOM 滚动实现，不合成鼠标滚轮事件。
- 快照感知页面与滚动容器的位置和可滚动状态，模型可据此判断滚动前后的页面变化。

### 定位作用域

- 步骤表支持定位作用域编辑：为步骤配置作用域容器（作用域策略、角色、名称与定位值），先定位唯一容器、再在容器内查找目标元素，应对弹窗、附件区等重复控件。
- 新增「拾取作用域」：在浏览器中选中需要作为作用域的容器，确认后仅更新作用域、保留目标定位器，无需重新拾取目标。
- 目标拾取按配置作用域校验：拾取的目标按作用域校验归属并生成容器内相对定位，避免跨容器混淆。

### 用例包 v2：随包携带测试文件

- `.testcase` 导出升级至 v2：引用了项目测试文件的上传步骤会随包导出（内嵌文件内容与哈希校验），导入时校验完整性并按需重建文件；未引用文件的用例仍保持 v1 格式，兼容旧版。

### 生成过程可控性

- 生成执行中可直接发送用户纠正：在生成页输入纠正说明（1~8000 字），当前操作结束后注入后续规划，无需中断整个生成流程。
- 空转守卫增强：新增短周期循环检测，相同动作连续 3 轮回到相同状态时及时触发人工求助，重复 9 次后自动中止，避免无意义的空转消耗；进展与观察计数生命周期重构，更准确地区分真实进展与空转。

### 登录状态与桌面主题

- 浏览器录制登录时持续保留最近一次成功快照，浏览器关闭后也能自动保存最近捕获的登录状态。
- 切换主题时同步 Tauri 原生窗口标题栏主题，跟随系统时清除覆盖，避免 WebView 媒体查询停留在强制主题。

### 修复与体验改进

- 删除计划中的断言步骤时，自动清理不再被引用的验收目标，避免遗留无效目标影响完成校验。
- 生成页测试文件列表仅保留本次上传的文件，不再混入历史文件。
- 窄视口下拾取工具条的确认/取消按钮不再溢出。
- 运行详情信息列限宽，完整报错通过悬浮提示展示。
- 用例详情脚本标签页侧栏宽度调整至 380px；插件表格列宽与长文本展示优化。
- README 演示素材更新为主流程视频。

### 升级说明

- **v0.1.3 及以上版本可通过应用内「软件更新」直接升级 v0.1.5；v0.1.2 及更早版本仍需手动安装 v0.1.3（含更新器）后再应用内更新。**
- 升级沿用现有应用数据目录，保留项目、脚本和配置；新增配置通过启动自动补齐，无需手动修改数据库。
- 测试文件、作用域与滚动动作由新生成的脚本使用；既有脚本与生成记录不受影响，回放保持兼容。
- 用例包 v1 继续支持导入；导出的 v2 包需升级到 v0.1.5 后导入。
- 验收完成仍表示生成过程中相应断言实际通过；建议生成后照例执行一次回归回放验证。

## v0.1.4（2026-09-12）：测试数据绑定、验收目标修订与断言诊断

本次更新聚焦 AI 生成过程的可控与断言可信：生成器填写的测试数据与断言期望自动绑定一致，生成挂起时可直接修订验收目标，断言失败给出可行动的定位诊断。同时新增复选框与单选组件插件，修复取消生成的用量漏记与录制脚本自愈失效问题。

### 测试数据绑定与冲突审查

- fill 与语义动作写入的实例值命中数据模板时自动反绑为占位符：脚本保存「数据模式」而非一次性实例值，同一占位符在回放中按相同规则解析，断言期望自动等于实际写入值。
- 生成中换值重试（regenerate）时自动同步该占位符的后续引用与断言预期，避免「填的是新值、断言的是旧值」的脱节。
- 计划确认页编辑填写值时，联动同步测试意图的数据约定与验收目标，保持三处口径一致。
- 首次确认前自动审查固定数据约定与计划取值的冲突，冲突时弹窗提示差异，可选择按计划值执行。

### 挂起等待与验收目标修订

- 计划确认与协助决策的等待时限由 5 分钟放宽至 2 小时，确认弹窗顶部显示倒计时，剩余不足 10 分钟转为警示色；超时或失败终态时自动收起弹窗。
- 求助挂起时新增「修订验收目标」：直接在协助面板调整验收数据与预期，护栏按修订后的标准放行，不再需要重新走完整确认流程。
- 断言与已确认验收目标不一致时被识别为合同错误：不计入失败求助计数、不触发机械式求助，而是直接回灌具体修订建议；协助面板移除了与其重复的「AI 修正」选项。
- 观察空转求助阈值支持按模型配置调整（2~20 次，默认 6）：按读图次数计价的模型可调大阈值以减少截图开销。

### 更可信的断言与快照

- 断言失败的报错区分定位失效与页面状态不符：明确提示「定位器 0 命中」或「命中 N 个元素（多匹配冲突）」，生成模型可据此立即换用正确定位器，减少反复试错和误触发人工求助。
- hidden 断言若在整个等待窗口内从未命中过任何元素，结果会附带「空断言」警示，防止选择器失效导致的恒真假通过。
- 换定位策略的重试按新定位器独立计数，不再与「同目标重试」混计，避免模型自我纠正时被误判为死循环。
- 快照采集覆盖 div onClick 指针卡片（列表记录卡此前对模型不可见，曾导致验收假阴性）；关键词查询在交互元素上 0 命中时，自动用页面文本二次判定并给出兜底提示。
- 提示生成模型在弹框出现后先等待动画完成再读取控件，降低弹框过渡期的误判。

### 新增复选框与单选组件插件

- 新增 Ant Design 与 Element 的复选框、单选按钮组插件：勾选/取消勾选幂等执行并等待受控状态落定，单选组按可见文本选中，禁用项明确报错。
- 兼容 Ant Design v5/v6 与 element-ui/element-plus。

### 修复与体验改进

- 修复取消生成时最后一步的在途调用用量漏记，用量对账纳入运行时累计兜底。
- 修复手动录制脚本不触发 AI 自愈的问题：自愈指令回退到步骤描述，录制与生成的脚本均可自愈。
- 运行记录详情与 Excel 导出中的自愈定位器改为 Playwright 链式写法的可读展示，不再显示 JSON 原文。
- 调整生成页主容器高度计算，优化页面布局。
- 重写中英文 README，新增快速上手演示视频与录制脚本；下载页改用构建时获取的更新清单并补充部署脚本。

### 升级说明

- **v0.1.3 用户可通过应用内「软件更新」直接升级 v0.1.4；v0.1.2 及更早版本仍需手动下载 v0.1.3 后再应用内更新。**
- 升级沿用现有应用数据目录，保留项目、脚本和配置；新增配置通过启动自动补齐，无需手动修改数据库。
- 测试数据绑定与验收目标修订在新生成会话中生效；既有脚本与生成记录不受影响，回放保持兼容。
- 观察空转求助阈值默认值由 4 调整为 6，可在应用配置中按所用模型的计价方式调整。
- 验收完成仍表示生成过程中相应断言实际通过；建议生成后照例执行一次回归回放验证。

## v0.1.3（2026-09-09）：测试意图与验收校验、桌面自动更新

本次更新加强 AI 生成测试的验收约束：生成前明确要验证的业务结果，生成过程中跟踪真实断言证据，所有必验目标通过后才允许完成。同时新增桌面更新入口，并修复主题与字号切换的一致性问题。

### 测试意图与验收约定

- 在原有计划确认窗口中配置正向、负向或混合场景，以及测试目标、前置条件、数据约束和清理要求，无需增加一轮确认。
- 为每个验收目标填写预期业务结果、具体验证范围、验收依据和断言条件，并标记是否必验；必验目标必须关联对应的计划断言。
- 加强负向测试与固定数据约束：生成器按已确认的要求执行，保留预期失败的输入和拒绝验证步骤；已确认目标的断言类型与预期不能被生成工具擅自替换或弱化。
- 验收约定随脚本版本保存，可在用例详情查看，并随另存版本、单条或批量导出及导入保留。

### 更精确的断言与完成校验

- 新增文本完全相等、字段值相等、选中与未选中、启用与禁用、匹配元素数量、URL 完全相等等浏览器断言；支持验证空字段和零匹配结果。
- 生成和回放使用一致的断言语义，并在超时范围内等待异步页面状态；文本完全相等比较会规范化空白。
- 只有实际执行成功并保存的断言才能登记验收通过。生成日志展示各项目标的覆盖状态，所有必验目标有有效证据且脚本末步为断言时才允许完成。
- 修改或删除相关执行步骤后，旧证据不再用于放行；暂停续跑和脚本审查后会重新核对证据。跳过必验项可以继续执行其他步骤，但不能报告完整完成。
- 回放中的断言失败不再通过 AI 重新定位来判定通过，减少真实问题被掩盖的风险；动作定位失败仍保留原有自愈能力。

### 桌面软件更新

- 侧栏新增「软件更新」，支持手动检查、查看下载进度和更新说明，以及关闭自动检查。
- 启用更新的正式桌面构建会在启动后、定期及网络恢复时检查最新正式版本，并自动下载更新包。
- 更新包通过签名验证后，由用户确认「重启并安装」，也可稍后处理。安装前会停止内置后端；安装失败时尝试恢复当前后端。
- 配套发布流程支持 macOS Apple Silicon、macOS Intel 和 Windows x64 的签名更新包与更新清单。

### 修复与体验改进

- 修复保存主题或字号后，全局组件样式与页面样式可能不同步的问题；设置变更后刷新界面以应用一致的配置。
- 调整生成输入区高度和用例列表创建时间列宽。
- 文档站首页根据浏览器语言选择中英文，并记住用户主动切换的语言；具体页面链接保持其指定语言。
- 调整 README 中英文入口，完善项目介绍与架构说明。
- 修复打包时 SQLite 空库模板的初始化问题，同步随安装包分发的后端、组件插件和数据库结构。

### 升级说明

- **从 v0.1.2 升级需手动下载安装 v0.1.3。** 旧版不含更新器；安装启用了更新功能的 v0.1.3 后，才可使用应用内更新获取后续版本。
- 自动更新依赖发布包中的更新公钥及已发布的签名更新资源。未配置公钥的本地构建不启用自动更新，浏览器版不提供更新入口。
- 升级沿用现有应用数据目录，保留项目、脚本和配置；新增字段通过启动迁移自动补齐，无需手动修改数据库。
- 已有脚本及没有测试意图的旧暂停任务继续兼容。原有 HTTP 接口和 WebSocket 回放断言保持支持，本次新增验收规划聚焦浏览器断言。
- 验收完成表示生成过程中相应断言曾实际通过，不代表已在全新环境中完整回放；建议生成后再执行一次回归验证。

## v0.1.2（2026-09-08）：首次发布

TestDog 是一款桌面端测试用例管理工具，将用例管理、AI 脚本生成、浏览器操作录制和自动化回放整合在一起，帮助你从测试描述走到可重复执行的测试脚本。

### AI 生成测试脚本

- 使用自然语言描述测试目标，结合起始地址、附件和登录配置生成脚本。
- 先确认 AI 拆分的步骤计划，再在真实浏览器中逐步执行并保存脚本。
- 支持暂停与继续生成；遇到问题时可使用 AI 修复、调整描述、手动接管或跳过步骤。
- 支持 OpenAI 兼容接口，可自行配置网关、API Key 和模型；视觉模型可结合图片附件和页面截图辅助生成。

### 浏览器录制与用例管理

- 录制浏览器操作并导入为可编辑的测试步骤。
- 保存登录状态，供脚本生成和回放复用。
- 按项目管理用例与脚本版本，支持拖拽排序、批量设置默认脚本版本。
- 支持 `.testcase` 文件单条或批量导入、导出。

### 自动化回放与测试报告

- 一键回放脚本，支持项目内用例批量无头运行。
- 支持页面 UI、HTTP 接口和 WebSocket 消息断言。
- 定位器失效时支持 AI 自愈，并可一键采纳修复结果、回写脚本。
- 记录失败截图、控制台日志和网络信息，支持导出 JSON / Excel 运行结果及 Excel 测试报告。
- 常规脚本回放无需调用大模型；AI 生成、修复和自愈需要调用所配置的模型服务。

### 组件插件与使用体验

- 内置适配 Ant Design、Element UI / Element Plus、Vant、MUI 的组件插件，覆盖下拉、树选择、级联、日期、时间和滑块等操作。
- 支持导入自定义 JavaScript / ZIP 插件，并通过预设组合使用。
- 支持生成过程日志与 Token 用量查看，以及随机测试数据变量。
- 提供简体中文 / English 界面、浅色 / 深色 / 跟随系统主题及字体大小设置。

### 安装说明

- **macOS**：此版本使用 ad-hoc 签名，未经过 Apple 公证。首次打开可能被系统拦截，确认安装包来源可信后，可在「系统设置 → 隐私与安全性」中手动允许打开。
- **Windows**：安装程序未使用付费代码签名证书，可能显示未知发布者或 SmartScreen 提示。
- AI 生成与自愈效果取决于模型能力和被测页面，建议检查生成的步骤及断言后再用于回归测试。
