# 快速开始

从安装到跑通第一条用例，大约需要 10 分钟。

## 1. 安装

- **macOS**：双击 `.dmg`，将 TestDog 拖入「应用程序」。
- **Windows**：运行 NSIS 安装包，按向导完成安装。

安装包内置 Node 运行时与浏览器执行环境，最终用户**无需安装 Node.js**。升级安装不会覆盖已有数据库，启动时会自动补齐新版本的字段。

::: tip 开发者模式
从源码运行：`npm install` → `npm --prefix server install` → `npm run tauri dev`。详见仓库根目录 README 的「开发运行」。
:::

## 2. 配置 AI 网关

AI 生成与自愈需要调用大模型（LLM）。TestDog 通过 **OpenAI 兼容协议**访问模型服务，所以任何兼容该协议的服务都能填：DeepSeek 官方、OpenRouter、公司自建网关/代理等。进入左侧「**设置**」页填写：

- **网关地址 / 密钥 / 模型名**（必填，均由你的服务商提供；如 DeepSeek 官方地址为 `https://api.deepseek.com`）
- **模型具备视觉能力**：开启后图片附件与页面截图以多模态直发主模型（模型需支持视觉）
- **思考深度**（仅推理模型需要，普通模型保持关闭）

详见[设置](/menus/settings)。

## 3. 创建项目与用例

1. 进入「**项目管理**」，新建一个项目，填**起始地址**（被测系统地址，生成/录制时默认从这里打开）。
2. 在项目内新建用例，填写标题与说明。

::: tip 被测系统需要登录？
先把登录态录成「登录配置」单独存一次，生成与回放就能以已登录状态进行，不必每条用例都测登录。见[测试数据与登录态](/guide/test-data)。
:::

## 4. 生成第一条脚本

三种方式，任选其一：

| 方式 | 适用 | 文档 |
| --- | --- | --- |
| **AI 生成** | 只会自然语言描述，或页面交互复杂 | [AI 生成脚本](/guide/ai-generate) |
| **手动录制** | 已知道每一步怎么点 | [手动录制脚本](/guide/record) |
| **导入 .testcase** | 同事分享的用例文件 / 编程 agent 生成 | [.testcase 用例文件](/guide/testcase-file) |

建议流程：**AI 生成第一版 → 人工微调步骤 → 回放验证 → 沉淀为回归用例**。

## 5. 回放运行

在脚本版本上点击运行，Playwright 确定性回放并执行断言；结果与失败诊断见「**运行记录**」。详见[回放运行](/guide/replay)。
