# 安全政策 / Security Policy

## 受支持的版本 / Supported Versions

| 版本 / Version | 支持 / Supported |
| --- | --- |
| 最新发布版 / Latest release | ✅ |
| 旧版本 / Older versions | ❌ |

## 报告漏洞 / Reporting a Vulnerability

**请勿通过公开 Issue 报告安全漏洞。**

请使用 GitHub 的私下漏洞报告功能：仓库 **Security** 页 → **Report a vulnerability**。

**Please do not report security vulnerabilities through public GitHub issues.**

Please use GitHub's private vulnerability reporting: the repo's **Security** tab → **Report a vulnerability**.

报告时请尽量包含：

- TestDog 版本与操作系统
- 漏洞类型与影响范围
- 复现步骤或概念验证（最小化）
- 相关截图、日志（如运行记录中的失败采集）

When reporting, please include where possible:

- TestDog version and operating system
- Vulnerability type and impact scope
- Minimal reproduction steps or proof of concept
- Relevant screenshots or logs (e.g. captured run-record diagnostics)

## 处理流程 / Handling Process

1. 我们会尽快确认收到报告，并与你保持沟通
2. 确认后在修复版本发布前不公开披露细节
3. 修复发布后会在 Release 说明中致谢报告者（除非你希望匿名）

1. We will acknowledge your report as soon as possible and keep you updated
2. Confirmed issues stay private until a fix is released
3. The reporter is credited in the release notes after the fix ships (unless you prefer to stay anonymous)
